3.2.5) Show that the sets Si are cumulative - that is, for each i, we have Si ⊆ Si+1

Proof: We will proceed by induction.

        Base Case: S0 ⊆ S1
        S0 = ∅ ⊆ S1 

        Inductive Case: Assume that Si-1 ⊆ Si
        Then 

        Si+1 = {true,false,0}
                ∪ {succ t1,pred t1,iszero t1 |t1 ∈ Si }
                ∪ {if t1 then t2 else t3 | t1,t2,t3 ∈ Si }
            ⊇  {true,false,0}
                ∪ {succ t1,pred t1,iszero t1 |t1 ∈ Si-1 }
                ∪ {if t1 then t2 else t3 | t1,t2,t3 ∈ Si-1 }
            = Si        

        Hence Si ⊆ Si+1



3.3.4)  Theorem [Principles of induction on terms]: Suppose P is a predicate on terms.
    Induction on depth:
    If, for each term s,

        we can show P(s),
    then P(s) holds for all s.

    If, for each term s,

    If, for each term s,
