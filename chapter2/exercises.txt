2.2.6) Suppose we are given a relation R on a set S. Define the relation R′ as follows:

R′ = R ∪ { (s,s) | s ∈ S }.

That is, R′ contains all the pairs in R plus all pairs of the form (s,s). 
Show that R′ is the reflexive closure of R.


Proof: 
Since { (s,s) | s ∈ S } ⊆ R' and R ⊆ R', 
    1.1) R' is a reflexive relation containing R.

Let R'' be any reflexive relation containing R, then we have,

    2.1) R ⊆ R''.
    2.2) { (s,s) | s ∈ S } ⊆ R''. 

By 2.1, 2.2, we have 

    2.3) R ∪ { (s,s) | s ∈ S } ⊆ R''

Hence by the definition of R'
    
    2.4) R' ⊆ R''

Combining 2.4 and 1.1 implies R' is a reflexive relation on S containing R and a subset of any other reflexive relation R''.

Thus R' is the smallest reflexive relation.
